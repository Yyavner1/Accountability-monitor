Works on macOS, Windows, and Linux.

Set up

  1. Unzip the download.
  2. Run the installer for your system:
    • macOS: ./install.sh
    • Linux: ./install_linux.sh
    • Windows: install_windows.ps1 (elevated PowerShell)
  3. Enroll this device on the dashboard to get an API key, and paste it (and this server's address) into config.json.
  4. Optional but recommended: turn on the website filter (sudo ./install_filter.sh) and install the browser extension from the extension folder.
