Three layers

How it protects you

Blocks adult sites

A system-wide filter stops known adult sites from loading in any browser or app.

Blurs explicit images

A browser add-on blurs explicit images and video on pages as they load.

Watches the whole screen

For everything else, it checks the screen on your machine and reports flagged moments to your partner — with an alert if you try to switch it off.

Setup · about 10 minutes, once

Getting it running on a Mac

  1. Download and unzip

    Get the code from GitHub (the green Code button → Download ZIP) and unzip the folder.

  2. Run the installer

    Open Terminal, go into the folder, and run the installer. It sets everything up and starts it automatically from then on.

    ./install.sh

  3. Open the settings page

    Instead of editing files, open the built-in settings page in your browser and fill in your partner's email, your email, and how often you want summaries.

    python3 -m accountability_monitor.webui \
  --config "$HOME/Library/Application Support/AccountabilityMonitor/config.json"

    You'll need a Gmail App Password so it can send email. Create one at myaccount.google.com/apppasswords.

  4. Allow it to see the screen

    In System Settings → Privacy & Security → Screen Recording, turn it on for the app's Python. Without this, the screenshots come out blank.

The one step people miss

Step 4, the Screen Recording permission. If your partner's reports look empty or all-black, that permission isn't granted yet — turn it on and restart.

Windows & Linux

Same idea: run install_windows.ps1 in PowerShell, or ./install_linux.sh on Linux. The settings page works the same way.

Day to day

Customizing it

Everything is in the settings page: who gets the reports, daily or weekly summaries, how sensitive the detection is, whether screenshots are blurred, and whether you're warned if the site filter is removed. There's a one-click Send test email button so you can confirm it's working before you rely on it.

The promise

Why this is private by design

Screenshots are checked on your own computer and are never uploaded anywhere. When something is flagged, a blurred image is emailed straight from your machine to your partner. There is no company server in the middle holding your screen activity, because there is no company server at all. You run the software; it answers to you.

Questions

Good to know

Is it really free?
Yes. It's open-source under the MIT license. The code is public on GitHub.
Can I just remove it myself?
You're the admin of your own computer, so yes — but doing so (or disabling it) sends an alert to your partner. It's built to make slipping unnoticed hard, not impossible.
Does it catch everything?
No tool does. It blocks a lot, blurs more, and reports the rest. The detection is on-device and best-effort, which is the honest trade for keeping it private.
Who can see my screen?
Only the accountability partner you choose, and only blurred images of flagged moments, sent directly to them. Not us — we run nothing.
